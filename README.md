# hw4_python
## Переписка Н. Эрдмана и А. Степановой (1928–1935)

# Источник:
Материалом послужил текст из [книги](https://fb2.top/pisyma-nikolay-erdman-angelina-stepanova-1928-1935-gg-457615), содержащей переписку писателя-драматурга Николая Эрдмана и его возлюбленной Ангелиной Степановой, актрисы МХАТа. 
В тексте есть сами письма (с 1928 по 1935 гг.), а также фрагменты из воспоминаний Степановой (опубликованных в 1995 году и относящихся к этому периоду). Воспоминания в датафрейм НЕ включены.

**Задачей** было подготовить датасет писем для дальнейшего количественного анализа. 

## Структура датасета:
| Столбец | Тип | Описание |
|---|---|---|
| `date` | datetime | Дата письма в формате YYYY-MM-DD; `NaT`, если восстановить не удалось |
| `author` | str | `Эрдман` или `Степанова`; `NaN`, если автоматически восстановить не удалось |
| `text` | str | Очищенный текст письма (без сносок и переносов строк) |
| `lemma` | str | Лемматизированный текст (pymorphy3) |
| `n_words` | int | Число слов в лемматизированном тексте |

## Методы извлечения и очистки данных:
1. Текст разбивается по разделителю `* * *`.
2. Блоки, начинающиеся с `[Воспоминания`, отбрасываются.
3. В каждом блоке выделяется шапка `header` (строки с адресом/датой) и тело `body`.
4. Дата парсится каскадом регулярок (DD.MM.YYYY, DD/Рим-YY, DD месяц [YYYY], месяц YYYY, YYYY, DD месяц).
5. Автор определяется по адресанту в шапке или по подписи в конце.

## Очистка и лемматизация:
- Удаляются сноски `[N]`.
- Переносы строк заменяются пробелами, пробелы схлопываются.
- Лемматизация: `pymorphy3`, только кириллица (`[а-я]+`), нижний регистр.

## Пропущенные даты:
- Если дата указана без дня, то день `01`.
- Если дата указана без года, то подставляем год предыдущего письма с явным годом.
- Если год восстановить нельзя → `NaT`. Таких писем: 26.
- Телеграммы без даты (`«26.12 часов»`) — `NaT`.

## Ограничения:
- Всего извлечено 75 писем.
- `NaT` в `date`: 26 писем.
- Возможны единичные ошибки в годе для писем без явного года — проверялись вручную по контексту.
